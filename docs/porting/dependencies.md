Each query filters Minecraft 26.2, then checks `forge` in each version's loader array. A project's combined loader/version list does not establish a compatible artifact. ## Native scope and JEI API boundary — 2026-09-14

The target bridge checks that interface before asking isAccelerated; BedrockPartMixin uses the guarded query before obtaining an extension. `verifyPortingARConsumers` checks actual TACZ VertexCapture and target BufferBuilder against the real old interface (six assertions). `verifyPortingARAbsent` removes the AR artifact from its classpath and checks facade linkage/absence behavior (five assertions). These do not validate a working AR companion, its Mixins, shaders, batching or performance.

## Core dependency boundary and packaging — 2026-09-15

Cloth's published `me.shedaniel.cloth:cloth-config:26.2.155` contains loader-independent common classes and no mod descriptor. Its POM has a Fabric loader runtime dependency; `transitive = false` deliberately prevents resolving that loader. `basic-math:0.6.1` supplies the widget signature. Both are compile-only. The compile/runtime dependencyInsight logs (`cloth-*-dependency-99.log`) confirm the common artifact is present only on the compile classpath. No Fabric/NeoForge implementation is used as a Forge substitute. Archive/source/POM hashes and inspection are in `cloth-common-api-2026-09-14.json`.

The full-port prompt permits isolating optional integrations when no target companion is available. `gradle/optional-adapters.gradle` retains eleven KubeJS classes, five Player Animator animation classes and the KubeJS discovery resource in dedicated source sets, plus a new Player Animator forwarding adapter. All 18 source/resource entries ship in the source archive. Core APIs and absence behavior remain available. `OptionalIntegration` resolves an implementation only when its companion is installed; an incompatible/missing provider fails explicitly with the original cause. This is not a placeholder implementation or a claim of companion-present support.

`verifyOptionalAdapters --continue` still fails: two KubeJS and eight Player Animator diagnostics against their recorded old signatures (run 98). KubeJS/Rhino/Architectury/Player Animator old JARs are no longer on the main compile or runtime classpath. Exact-version provider queries again returned no KubeJS/Rhino/Player Animator 26.2 artifacts; scope and URLs are in `blocked-companions-2026-09-14.json` (queried UTC 2026-09-15). These are externally blocked full-port parity requirements. Other legacy optional compile signatures remain temporary and unreleasable.

Core build 97 packages 935 TACZ classes and six declared nested libraries: MixinExtras Forge 0.5.4, LuaJ core/JSE 3.0.8-figura, BCEL 6.6.1, Commons Math 3.6.1 and MAE 1.1.2. `core-candidate-97.json` records each nested hash, notices and optional-source inclusion. It reports Windows OSHI/Netty host diagnostics; full client/gameplay closure, optional integrations and release licensing review are still required.
