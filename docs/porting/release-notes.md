# Unreleased Forge 26.2 port

**Development candidate only; full port and release gates remain incomplete.**

Target: Minecraft Java 26.2, Forge 65.1.0, Java 25. Mod ID `tacz`, version `1.1.8-hotfix-port.1`. Build 101 produces `build/libs/tacz-26.2-1.1.8-hotfix-port.1.jar` (SHA-256 `a320d7a8dc613352addf99e66caf79d1deb3009a0951b0ce648b385fe24a0c71`). This is not an approved end-user release.

The core now compiles and packages. All 28 focused tasks pass 1,783 assertions, including persistence/recipe/network primitives, model geometry, native render descriptions and OpenGL/Vulkan scope fixtures. A fresh official Forge dedicated-server installation containing only the candidate loads its default pack and 1,769 recipes, reloads TACZ and vanilla data, saves and stops normally. OSHI/Netty host diagnostics remain recorded separately. The complete packaged mod also passes 66 development-client assertions per backend (OpenGL and Vulkan): content/world loading, held AK-47 animation, a survival shot, synchronized projectile and partial Lua reload with exact ammo use, followed by clean shutdown. Complete gameplay and visual/audio parity remain unverified.

This continuation adapts Cloth common API widgets, isolates retained unavailable KubeJS/Player Animator adapters, fixes dedicated-server class loading and packet callback isolation, defers item templates until target components bind, converts custom-data legacy loot functions, and fixes the post-firing client shutdown by stopping its scheduled executor through Forge. Periodic shots cancel their actual future instead of an invalid Thread cast. Native scope rendering, data components, events/networking, blocks/recipes, UI and other earlier port work remain preserved. Public API changes and unsupported migration cases are listed in migration.md.

The official installed release profile also passes the 66 instrumented checks on both backends; TACZ-only OpenGL/Vulkan clients reopen a prepared test world and save/close normally.
